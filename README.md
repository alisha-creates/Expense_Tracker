# # NexSpend — Smart Expense & Finance Management System

NexSpend is a full-stack **expense tracking and personal finance management application** built using **Spring Boot, Spring Security, JWT, MySQL, JPA/Hibernate, HTML, CSS, and JavaScript**.

It helps users securely manage income and expenses, monitor their spending habits, manage budgets, generate reports, and receive automated email notifications.

---

## 🚀 Features

### 🔐 Authentication & Security

* User registration and login
* JWT-based authentication
* Access token and refresh token support
* Role-based access control
* Secure password hashing
* Email account activation
* Password change functionality
* Current-password verification before changing password
* Password visibility toggle
* Logout functionality
* Token expiration and refresh mechanism
* Rate limiting and security filters

### 💰 Expense & Income Management

* Add income and expenses
* Edit existing transactions
* Delete transactions
* Soft-delete support
* Transaction categorization
* Income/expense type classification
* Transaction date tracking
* Amount validation
* Search and filter transactions
* Sorting and pagination

### 📊 Dashboard

The dashboard provides a financial overview including:

* Total income
* Total expenses
* Current balance
* Monthly spending
* Category-wise expenses
* Income vs. expense analysis
* Recent transactions
* Budget information
* Interactive charts and statistics

### 🗂️ Expense Categories

NexSpend supports categories such as:

* FOOD
* TRAVEL
* SHOPPING
* HEALTH
* EDUCATION
* ENTERTAINMENT
* And other customizable categories

### 🎯 Budget Management

* Create budgets
* Set spending limits
* Track budget utilization
* Compare actual spending with planned budgets
* Monitor overspending

### 📧 Email Notifications

NexSpend supports automated email notifications for:

* Account activation
* Daily expense reminders
* Daily financial summaries
* Password-change notifications
* Monthly financial reports

Scheduled notifications can be configured using Spring's scheduling mechanism.

### 📄 Financial Reports

Users can generate financial reports containing:

* Income summary
* Expense summary
* Balance
* Category-wise spending
* Transaction details
* Monthly financial statistics

Reports can be generated in:

* **PDF**
* **Excel**

### 👤 Account Management

Users can manage:

* Profile information
* Password
* Account activation status
* Authentication sessions
* Logout
